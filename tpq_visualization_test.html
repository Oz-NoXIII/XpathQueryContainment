TreePatternQuery visualisation

Les cercles contiennent les labels. Les traits simples représentent les liens child/parent, les doubles traits les liens descendant/ancestor.

Thème

Requête XPath :

(
  self[
    (
      lab = *
    )
    &
    ?descendant[
      (
        lab = c
      )
    ]
    &
    ?ancestor[
      (
        lab = a
      )
      &
      ?child[
        (
          lab = b
        )
        &
        ?child[
          (
            lab = c
          )
        ]
      ]
      &
      ?descendant[
        (
          lab = e
        )
      ]
    ]
  ]
  /
  child[
    (
      lab = d
    )
  ]
)
